Versión 3.12.17

Correcciones puntuales sobre 3.12.16, conservando el diseño visual existente.

1. El botón ☰ ahora muestra únicamente el icono de tres barras (sin el carácter de texto duplicado).
2. La opción Historial llama al gestor de historial para llenar la lista y mostrar la partida seleccionada.
3. Los mensajes del modo individual y clásico vuelven a registrarse en el historial.
4. No se cambia la clave de almacenamiento local, para que las partidas ya guardadas en el mismo origen sigan siendo accesibles.

Nota: las partidas se guardan en el almacenamiento local del navegador y del origen web donde se jugó. No se sincronizan automáticamente entre dominios o dispositivos.
