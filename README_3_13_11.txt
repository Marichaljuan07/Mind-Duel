MIND DUEL FUSION 3.13.11 — BIBLIOTECA E IMPORTACIÓN DE GUARDADOS

Novedades:
- En Recuperar partida se puede importar un respaldo JSON.
- Cada partida de la biblioteca permite continuar/revisar, renombrar, exportar su respaldo JSON y eliminar solo esa copia de la biblioteca.
- El respaldo individual incluye la perspectiva que tenía guardada ese jugador: rol, contadores, conversación y estado disponible.
- Se puede importar el respaldo de la otra persona para abrir su perspectiva guardada en este dispositivo, siempre que el archivo contenga esos datos.
- Importar no sobrescribe automáticamente la sesión actual ni combina dos copias. Eso evita mezclar roles o revelar el personaje secreto del Cerebro al Descubridor.
- Los archivos históricos que solo contienen mensajes se pueden revisar, pero no se puede garantizar una reconexión si no contienen estado de sesión y datos de sala suficientes.

Pruebas realizadas: sintaxis JavaScript y comprobación de integridad del ZIP. No se ha podido validar una partida online real con dos dispositivos desde este entorno.
